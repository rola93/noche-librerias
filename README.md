# Noche de las Librerías · Guía no oficial

[noche-librerias.netlify.app](https://noche-librerias.netlify.app/)

Guía navegable y filtrable de la Noche de las Librerías en todo Uruguay: librerías, horarios, actividades y descuentos, pensada para usar desde el celular.

Proyecto de código abierto e iniciativa personal de Rodrigo Laguna, sin vínculo con los organizadores. Sugerencias y correcciones: abrí un issue o un PR, o escribí a r.laguna.queirolo@outlook.com.

- `site/index.html`: la guía publicada (un único HTML autocontenido).
- `_build/`: datos curados y scripts para regenerarla (`python3 _build/build.py`).

Se publica en Netlify automáticamente al mergear a `main`.
